------------------------------------ Token and altcoin in Block Chain --------------------------------

1. What is Token in Block Chain ?
- A Token is a digital asset created and managed on a blockchain.
- It represents some value, right, or utility, but unlike a coin (like Bitcoin or Ethereum), a token does not always have its own blockchain.
- Instead, it is usually built on top of an existing blockchain (e.g., Ethereum, Solana, Binance Smart Chain).

Note: 
- Coins → BTC (Bitcoin), ETH (Ethereum) → have their own blockchain.
- Tokens → USDT (Tether), UNI (Uniswap Token), MATIC (on Ethereum initially) → are built on top of another blockchain using standards like ERC-20 (Ethereum).

2. What is AltCoin in Block Chain? 
- The word Altcoin comes from "Alternative Coin".
- Bitcoin was the first cryptocurrency (2009).
- After that, many other coins were created with different features, improvements, or purposes.
- All of those are called Altcoins.

3. Examples of Altcoins:
- Ethereum (ETH) → Smart contracts and decentralized apps.
- Ripple (XRP) → Fast, low-cost cross-border payments.
- Litecoin (LTC) → Faster transactions than Bitcoin.
- Cardano (ADA) → Focus on scalability and sustainability.
- Polkadot (DOT) → Connects multiple blockchains.
- Dogecoin (DOGE) → Meme-based coin, but widely popular.

4. Types of Altcoins:
- Stablecoins → Pegged to fiat (e.g., USDT, USDC).
- Utility Tokens → Used for platform services (e.g., BNB on Binance).
- Security Tokens → Represent ownership in assets.
- Meme Coins → Fun/community-driven coins (e.g., DOGE, SHIBA INU).
- Governance Tokens → Voting rights in DeFi projects (e.g., UNI, AAVE).
