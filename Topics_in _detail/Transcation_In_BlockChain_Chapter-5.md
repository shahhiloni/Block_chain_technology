-------------------------------- Transcation in Blockchain -----------------------------------

1. What is a Transaction in Blockchain?
- A transaction in blockchain is just like an entry in a digital ledger.
- It represents the transfer of value or information between two parties.

2. Steps of a Transaction in Blockchain
- 1. Initiation → A person requests a transaction (e.g., sending cryptocurrency).
- 2. Verification → The transaction is broadcasted to the blockchain network (nodes).
- 3. Validation → Miners/validators check if Alice really has 1 Bitcoin (using consensus mechanism like Proof of Work or Proof of Stake).
- 4. Block Formation → The valid transaction is grouped with other transactions into a block.
- 5. Added to Blockchain → Once verified, the block is added to the chain permanently.
- 6. Completion → Bob receives 1 Bitcoin.

3. Properties of a Blockchain Transaction
- 1. Immutable → Once recorded, it cannot be changed or deleted.
- 2. Transparent → Anyone on the network can view it.
- 3. Secure → It uses cryptography (digital signatures, hashing).
- 4. Decentralized → No single authority controls it.

Note: A blockchain transaction = “a verified and recorded transfer of value/information stored permanently in the blockchain ledger.”
